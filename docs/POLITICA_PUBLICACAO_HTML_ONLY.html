Regra do espaco

No domínio publicado, documento visível deve ser HTML. Fonte crua, script operacional e rascunho ficam fora de docs.

Gate de publicação

Política HTML-only para o docs

O site publicado deve expor páginas HTML com navegação valida e estilo harmônico. Arquivos de apoio técnico podem existir como assets de renderizacao, mas documentos, notas operacionais e scripts não devem permanecer dentro de docs/.

html-only shell harmônico sem artefato cru

Regras operacionais

  • Documento publicado no portal: sempre .html.
  • Nomes de arquivos .html em caixa baixa (URLs estáveis em servidores case-sensitive e alinhamento com o catálogo).
  • Arquivos fonte como .md, .txt, .py, .csv, .htm e equivalentes não podem permanecer na arvore publicada.
  • Assets técnicos de renderizacao podem permanecer quando forem estritamente suporte de página: .css, .js, imagens e fontes.
  • Excecao operacional explicita: feed.xml e permitido somente para distribuicao de feed público (sindication).
  • Subportais com identidade própria continuam permitidos, desde que respeitem navegação, hierarquia e integracao com o shell do site.
  • Todo novo documento entra no portal com metadata básica, link institucional e visual coerente com a coleção onde vive.

O que bloqueia publicação

  • README operacional, prompt, plano bruto ou nota de continuidade publicado diretamente dentro de docs/.
  • Script Python ou PowerShell acessivel pelo mesmo caminho da documentação web.
  • Indice usando extensão legada .htm em vez de .html.
  • Página nova sem shell harmônico ou sem links de retorno para o portal/hub.

Fluxo recomendado para migrar material cru

  1. Escolher o material bruto fora de docs/ como fonte de trabalho.
  2. Produzir a versão publicada em HTML usando o shell do portal ou a identidade local autorizada.
  3. Apontar navegação do hub para a página HTML final.
  4. Executar a auditoria com python scripts/check_docs_html_only.py --report-only.
  5. Se a auditoria retornar zero violacoes, liberar para deploy.

Validação automatica

Script institucional: scripts/check_docs_html_only.py.

  • Modo de auditoria: python scripts/check_docs_html_only.py --report-only
  • Modo de gate: python scripts/check_docs_html_only.py
  • Saida esperada: total de violacoes, agrupamento por extensão e diretorios com maior passivo.

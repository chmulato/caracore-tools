Regra do espaco

No dominio publicado, documento visivel deve ser HTML. Fonte crua, script operacional e rascunho ficam fora de docs.

Gate de publicacao

Politica HTML-only para o docs

O site publicado deve expor paginas HTML com navegacao valida e estilo harmonico. Arquivos de apoio tecnico podem existir como assets de renderizacao, mas documentos, notas operacionais e scripts nao devem permanecer dentro de docs/.

html-only shell harmonico sem artefato cru

Regras operacionais

  • Documento publicado no portal: sempre .html.
  • Arquivos fonte como .md, .txt, .py, .csv, .htm e equivalentes nao podem permanecer na arvore publicada.
  • Assets tecnicos de renderizacao podem permanecer quando forem estritamente suporte de pagina: .css, .js, imagens e fontes.
  • Excecao operacional explicita: feed.xml e permitido somente para distribuicao de feed publico (sindication).
  • Subportais com identidade propria continuam permitidos, desde que respeitem navegacao, hierarquia e integracao com o shell do site.
  • Todo novo documento entra no portal com metadata basica, link institucional e visual coerente com a colecao onde vive.

O que bloqueia publicacao

  • README operacional, prompt, plano bruto ou nota de continuidade publicado diretamente dentro de docs/.
  • Script Python ou PowerShell acessivel pelo mesmo caminho da documentacao web.
  • Indice usando extensao legada .htm em vez de .html.
  • Pagina nova sem shell harmonico ou sem links de retorno para o portal/hub.

Fluxo recomendado para migrar material cru

  1. Escolher o material bruto fora de docs/ como fonte de trabalho.
  2. Produzir a versao publicada em HTML usando o shell do portal ou a identidade local autorizada.
  3. Apontar navegacao do hub para a pagina HTML final.
  4. Executar a auditoria com scripts/check-docs-html-only.ps1 -ReportOnly.
  5. Se a auditoria retornar zero violacoes, liberar para deploy.

Validacao automatica

Script institucional: scripts/check-docs-html-only.ps1.

  • Modo de auditoria: powershell -File scripts/check-docs-html-only.ps1 -ReportOnly
  • Modo de gate: powershell -File scripts/check-docs-html-only.ps1
  • Saida esperada: total de violacoes, agrupamento por extensao e diretorios com maior passivo.

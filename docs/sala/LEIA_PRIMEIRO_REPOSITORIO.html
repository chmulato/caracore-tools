Cara Core Informática · Instruções para quem opera (ex.: jovem 16 anos, 3h/semana). O Seed e o MKT são da Cara Core; não vendemos.

Premissa: A sala é pública e transparente. O diferencial competitivo está no valor da execução; a recompensa é proporcional à entrega validada. Ver regis/TEXTO_RECEPCAO, regis/ESTRATEGIA_EXECUCAO, regis/GUIA_EXECUCAO_JOVEM e regis/ARQUITETURA_SALA_C4.

Referência de uso: a Sala de Operações deve ser consultada pela sua versão oficial no portal.

Organização da Sala: a visão geral de como os materiais se distribuem entre controle, campanhas, apoio e registros está em Estrutura da sala.

1. CONTEÚDO DESTE REPOSITÓRIO (sala)

  • Instruções em formato para leigos, com desenhos (Passos 1–4) — leigo_c1_c2_c3_c4.html. C1–C4 = modelo C4 (Contexto, Contêineres, Componentes, Código); ver c4_modelo.html.
  • Material sempre em HTML; em cada página de artefato há caixa "Texto para colar na IA" e instruções para salvar no formato correto.
  • Assets por rede: sala/assets/, face/, gram/, retro/.
  • Script Python no final para validar se o trabalho foi executado com sucesso.

2. AUTOMAÇÃO DE APOIO

A Sala conta com automações de apoio para validação e conferência do trabalho ao final de cada rotina. Elas servem para confirmar se tudo foi salvo e organizado corretamente.

3. AUTOMAÇÃO — ONDE CADA REDE ENCAIXA

  • Facebook (F): face/
  • Instagram (G): gram/
  • LinkedIn: segue a continuidade editorial já registrada no manual LinkedIn da Sala.

Tudo precisa encaixar com clareza: cada rede mantém sua própria organização, e a campanha do LinkedIn segue seu manual específico dentro da Sala de Operações.

4. VALIDAÇÃO NO FINAL DO TRABALHO

  1. Salve todos os arquivos com nome correto e na área certa da rede correspondente.
  2. Use a validação de apoio disponível para conferir se a rotina foi concluída corretamente.
  3. Se a validação confirmar que está tudo certo, o trabalho pode ser considerado concluído.
